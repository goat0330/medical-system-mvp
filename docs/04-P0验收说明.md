# P0 本地化验收说明

## 病历编辑质控

1. 打开“病历编辑质控”。
2. 左侧可见：病案首页、入院记录、病程记录、手术记录、出院记录。
3. 中央为本地编辑器工具栏 + A4 医疗文书纸张，不允许显示 JSON。
4. 入院记录顶部显示 4 条质控提醒；正文“现病史”后显示红色内联质控。
5. “忽略 / 忽略全部 / 查看全部 / 去评估”可交互。
6. 点击“保存草稿”后写入 localStorage；点击“医生确认”后当前文书进入只读。
7. 关闭网络后刷新，以上功能仍可运行。
8. UI 中不得出现第三方编辑器品牌或远程 SDK 状态。

## 医保结算清单

1. 页面使用 Gold Master PageHeader / Sidebar / Card 体系。
2. 清单主体按三页纸张式展示。
3. 患者、诊断、手术、住院过程和费用均来源于同一 Episode。
4. 可以重新质控和浏览器打印/PDF。
