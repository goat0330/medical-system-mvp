# 前端设计系统与组件映射

本项目以 `medical-system-mvp-ui-gold-master-v1.zip` 中的设计系统为唯一视觉母版。

核心映射：

- `app/design/tokens.css`：颜色、字号、间距、圆角、阴影；
- `app/design/layouts.css`：AppShell / Sidebar / PageHeader / Workbench；
- `app/design/components.css`：Button / Card / Badge / Table / Tabs；
- `app/design/medical.css`：医疗工作台、DRG、审核领域组件；
- `app/design/record-editor.css`：病历编辑质控本地组件；
- `app/domain/medical-record-editor.js`：模板加载、数据元映射、编辑和保存。

业务开发不得新建平行视觉体系。新增页面优先组合现有 primitives 与领域组件。
