# 病历编辑质控本地化说明

本模块在产品中统一称为“病历编辑质控”。

运行时由以下本地资源组成：

- `app/domain/medical-record-editor.js`：编辑、数据元映射、快照、只读控制；
- `product/medical-record-templates/`：住院文书模板；
- `app/design/record-editor.css`：工具栏、纸张、数据元和质控提示视觉；
- `app/domain/quality-control.js`：当前 P0 质控提醒数据。

模板数据元已经转换为项目命名：

```text
data-med-code
data-med-name
data-med-node
```

整个运行链路：

```text
Episode
  ↓
本地模板
  ↓
数据元映射
  ↓
病历编辑
  ↓
质控提醒 / 正文定位
  ↓
保存草稿 / 医生确认
```

不依赖远程脚本、远程模板或外部编辑器服务。
