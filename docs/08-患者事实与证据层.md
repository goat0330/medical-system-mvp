# 患者事实与证据层

## 目标

所有下游业务不再各自直接从某份文书中“找一个值”，而是统一经过：

`Evidence → ClinicalFact → Conflict/Decision → ConfirmedFact → Projection`。

## EvidenceItem

保存来源系统、来源文书、字段编码、版本/保存时间、原始值、事件时间和摘录。

## ClinicalFact

统一 canonical concept，例如：

- `patient.age`
- `patient.birthDate`
- `diagnosis.principal.code`
- `procedure.primary.code`

状态包括 `CANDIDATE / CONFIRMED / CONFLICTED / REJECTED / SUPERSEDED`。

## FactConflict

同一事实存在多个不一致来源，或派生逻辑不一致时生成。关键人口学、主要诊断、主要手术等冲突默认阻断正式分组。

## FactDecision

医生/编码员/审核员人工裁定使用哪个候选值。裁定本身也是数据血缘的一部分，不删除原始证据。

## Projection

- FrontPageProjection
- SettlementProjection
- GroupingProjection
- AuditProjection
- DocumentProjection

后续六类质控统一输出 QualityIssue，并复用同一 Fact/Evidence 底座。
